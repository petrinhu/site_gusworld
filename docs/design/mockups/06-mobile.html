Decidido: d-pad de toque + parado até o input. O líder reverteu o "auto-anda" (achou que começar andando sozinho não faz sentido). Vale em todo lugar: no desktop é clique + WASD; no celular é o d-pad. Sem anda-sozinho, com colisão, quadrado azul sólido e o sprite certo do Gus.

Histórico (o que foi comparado antes da decisão):
1. D-pad na tela (o escolhido).
2. Toque e arraste (vira empurrar em vez de pilotar).
3. Auto-anda + toque para assumir (revertido: o "anda sozinho" não fez sentido ao vivo).
4. Desktop-only (entregaria o brinquedo a quem menos precisa: a criança chega de celular).

prefers-reduced-motion: o quadrado entra já virado (o Gus, parado no destino) e a legenda de texto conta a história; o jogo nunca é o único caminho para a informação.
