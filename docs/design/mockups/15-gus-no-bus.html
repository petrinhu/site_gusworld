A secao recorrente "Gus no Bus": as ideias que o Gus manda pelo bus git viram materia. O centro agora e o ARTEFATO REAL: o arquivo ideias1.txt inteiro que o menino subiu, verbatim (a grafia dele preservada: "Opcoes", "aleatorio", "depedendo", "voce", "nao"). A fala narra o destino das 4 ideias (verdade, da issue #1); o caderno mostra o arquivo do jeito que chegou; o // pensa sobre a mancha.

⚙️ Manchas reworkeadas: borda organica por filtro SVG (feTurbulence + displacement), nao mais "lente" limpa. No hero, chocolate (cauda em branco, base-esquerda) + uma gota de suco de uva (canto do cabecalho). O item demo embaixo ilustra o caso "nao deu, sem spoiler" + a variacao sem mancha (as 4 reais nao tem esse caso). Tudo CSS puro, zero JS. Manchas nunca sobre o texto (zona livre + overflow:hidden).

As ideias chegam manchadas

Toda edição, o Gus manda ideia pelo bus: às vezes uma, às vezes um arquivo inteiro de uma vez. Umas viram jogo, outras não (e ele não conta por quê, pra não estragar surpresa). A gente imprime o pedido do jeito que chegou: o arquivo dele, a grafia torta, a mancha que ele jura que estava longe do texto.

como ler: gus@glyfesse> é o Gus contando o que aconteceu com cada ideia · o papel pautado é o arquivo original que ele subiu pelo bus, verbatim (a grafia é dele) · // é o que ele pensa depois, olhando a mancha
