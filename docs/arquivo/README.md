# `docs/arquivo/`: o arquivo histórico do projeto

A Glyfesse é build-in-public, e por isso o site também é **o arquivo** do que o jogo já foi.
Quando uma sessão irmã (jogo, glintfx) aposenta um documento cujo objeto deixou de existir,
o conteúdo vem para cá **integral** em vez de ser jogado fora.

A regra, dita pelo líder quando as memórias da era Godot foram aposentadas:

> "elas vão sobreviver lá. Aqui não é cemitério."

Ou seja: **memória de trabalho fica só com o vivo; o registro de como o projeto pensava fica aqui.**

Isto **não é** conteúdo publicado. É matéria-prima: uma edição pode citar, resumir ou linkar,
mas o arquivo existe mesmo que nenhuma edição use.

## Higiene (repositório público)

- Nome de batismo de menor **nunca** (só "Gus Dragon" / "playtester de 11 anos").
- Segredo, token ou chave **nunca**, mesmo em transcrição integral.
- Dado pessoal de terceiro (e-mail, telefone) é **redigido**, com nota dizendo que foi.
