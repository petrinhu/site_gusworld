## EN

`gus@glyfesse>` first edition

This magazine is called Glyfesse. I'll explain it, because it's the only thing here that needs explaining. `glyfa` is glyph: a code-word. `-esse` is the collective, the abstract. Put them together and you get "the Writing." In the language I think in, the verb `glyfe` means to write and to compile. One word, both meanings. So Glyfesse #1 is the first edition and the first build. It's not a pun. It's the language.

One detail, if you notice. The world was written before it was compiled. The lore came first, the code after. So this edition is exactly that, literally: the writing before the compilation. The rest is still compiling... but you got here in time to see the start.
